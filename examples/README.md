# Ejemplos completos

Son tres carpetas de contexto ficticias. Leelas para ver el nivel de detalle, no para copiar hechos o condiciones comerciales a tu actividad. Los nombres, negocios, métricas y decisiones fueron creados para ilustrar el uso del kit.

- **Lucía:** arquitecta independiente; servicios por etapas, revisiones, entregas y capacidad personal.
- **Martín:** dueño de una pyme de mantenimiento; coordinación de equipo, órdenes, materiales y compromisos.
- **Paula:** dueña de una ferretería; atención, pedidos por WhatsApp, compras y stock.

Las carpetas conservan sus nombres originales para mantener las rutas. El contenido de esta edición representa estos nuevos perfiles.
