# Usá tu contexto con tus herramientas

Empezá donde ya trabajás. No necesitás instalar una integración para aprovechar estos documentos.

| Tu situación | Por dónde empezar | Qué mantenimiento requiere |
| --- | --- | --- |
| Querés probar una tarea en un chat | [Copiar y pegar](system-prompt-patterns.md) | Pegar la versión actual cada vez que corresponda |
| Usás ChatGPT para varias tareas relacionadas | [Proyectos en ChatGPT](chatgpt-projects.md) | Reemplazar los archivos subidos cuando cambien |
| Usás Claude para varias tareas relacionadas | [Proyectos en Claude](claude-projects.md) | Reemplazar los archivos subidos cuando cambien |
| Ya tenés un agente OpenClaw configurado | [Contexto para OpenClaw](openclaw-agents.md) | Verificar qué archivos lee y cuándo los vuelve a consultar |
| Tenés soporte técnico y necesitás acceso desde herramientas compatibles | [MCP](mcp-resource.md) | Mantener permisos, servidor y lectura de versiones |
| Estás construyendo una aplicación propia | [Diseño de una API](api-layer.md) | Implementar y operar un servicio con controles por cliente |

Las últimas tres opciones son guías para integraciones que tendrías que configurar. Este repositorio no incluye servidores, automatizaciones ni conexiones activas.

## Elegí el contexto para la tarea

- **Propuesta o presupuesto:** identidad, conocimiento del rubro y límites. Sumá los datos confirmados del encargo.
- **Respuesta a una consulta:** identidad, estilo y límites.
- **Planificación semanal:** responsabilidades, proyectos, objetivos y límites.
- **Preparación de una reunión:** proyectos y vínculos relevantes.
- **Comparación de alternativas:** objetivos, límites y registro de decisiones.

Usá documentos finales, no las plantillas con preguntas. Compartí lo necesario y separá el contexto de distintos clientes.

## Comprobá que sirve

Pedí un borrador para una tarea conocida. Verificá que respete tono, alcance, horarios y datos confirmados. Después cambiá un dato de prueba, actualizá la copia y comprobá que la siguiente respuesta use la versión nueva. La disponibilidad de un archivo no garantiza que se haya consultado para cada respuesta.
